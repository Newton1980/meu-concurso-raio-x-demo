# MEU CONCURSO — QSCon 2027 | DEMO 2.2.2

Pacote pronto para GitHub Pages. **O painel ainda não foi publicado.**

1. No GitHub, crie um repositório público com nome `meu-concurso-raio-x-demo` (ou outro nome).
2. Envie os arquivos **desta pasta**, na raiz do repositório: `index.html`, HTML com nome personalizado, `contest-data.json`, `.nojekyll`, `SHA256SUMS.txt`.
3. Acesse Settings > Pages > Build and deployment > Deploy from a branch; selecione `main` e `/ (root)`; salve.
4. Aguarde a publicação e abra `https://Newton1980.github.io/meu-concurso-raio-x-demo/` (ajuste o nome se diferente).
5. Teste no Chrome Android, inclusive os links oficiais, seleção de especialidade, prazos, navegação inferior e selo DEMONSTRAÇÃO.
6. Só então adicione o endereço à bio do Instagram ou ao adesivo de link nos Stories.

O arquivo com nome personalizado permanece disponível para distribuição, mas GitHub Pages usa `index.html` como ponto de entrada.

ATENÇÃO: repositório público permite acesso ao código e aos dados. Marca d'água e licença DEMO não impedem cópias. Não publicar dados pessoais. O conteúdo do edital deve ser conferido nas fontes oficiais.
